# Catálogo de API

Inventario extraído de anotaciones de controladores del commit base. No es un contrato OpenAPI generado en ejecución: revisar parámetros, DTO y respuestas en cada archivo. Las anotaciones encontradas no implican acceso público; los permisos se detallan en [Seguridad](seguridad.md).

## Registro de venta

```http
POST /api/v1/ventas
Content-Type: application/json
Authorization: Bearer <token del entorno>
```

```json
{
  "clienteNombre": "Cliente de demostración",
  "metodoPago": "EFECTIVO",
  "sesionCajaId": 1,
  "operacionId": "demo-operacion-unica-001",
  "detalles": [{ "productoId": 1, "cantidad": 1 }]
}
```

Los identificadores son ilustrativos: preparar producto, existencias y sesión autorizada reales del entorno. El backend obtiene vendedor del token y precio del catálogo; no se envía un total calculado por el navegador como fuente de verdad.
