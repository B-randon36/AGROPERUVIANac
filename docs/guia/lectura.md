# Cómo usar esta documentación

Esta web reúne el producto como un solo sistema empresarial. Las pestañas ADS, BD2 y LP2 organizan las evidencias por curso; comparten el mismo dominio y código.

## Rutas de lectura

| Perfil | Recorrido sugerido |
|---|---|
| Docente o jurado | Alcance → arquitectura → trazabilidad → checklist → sustentación |
| Desarrollador | Instalación → backend → frontend → API → pruebas |
| Responsable de base de datos | Datos → Oracle → operación → evidencias |
| Usuario de demostración | Instalación → uso del sistema → limitaciones |

## Convenciones

- Las rutas `backend/...` y `bomerp-frontend/...` son relativas a la raíz del repositorio.
- Los enlaces de fuentes apuntan a un commit concreto para conservar la trazabilidad.
- Los diagramas son vistas documentales construidas a partir del código; no son capturas de una ejecución.
- Los ADR reconstruidos explican decisiones observadas; el equipo debe revisarlos antes de declararlos acuerdos formales.
- Los nombres y asignaciones del equipo proceden del brief y README; su vigencia debe confirmarse con el equipo.

## Búsqueda

Utiliza la búsqueda superior para localizar `FEFO`, `VentaServiceImpl`, `Oracle`, `caja` o un identificador como `RN-VEN-06`. En pantallas pequeñas abre el menú lateral para acceder a las páginas.
