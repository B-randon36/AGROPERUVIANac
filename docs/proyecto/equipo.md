## Evidencia individual por completar

Cada integrante debe vincular al menos una regla, una clase o endpoint, un objeto de datos y una prueba de su módulo. Registrar también correcciones e integración con los demás módulos.

| Evidencia | Qué registrar |
|---|---|
| Cambio de código | Commit o PR y explicación del problema resuelto |
| Diseño | Diagrama o ADR y correspondencia con la implementación |
| Base de datos | Script y salida verificable en el entorno usado |
| Prueba | Caso, entrada, resultado esperado, resultado real y fecha |
| Defensa | Demostración que el integrante pueda reproducir |
